# Museum of the Year 3000

A museum label from the year 3000, placed beside an ordinary object from today — written by a small deterministic program.

> Group chat. Forty-seven people, one conversation, zero decisions.

`main.ts` writes that line (65 characters) to `/output/entry.txt`. No network, no dependencies, no secrets — just Node's standard library.
